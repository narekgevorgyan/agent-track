# agent-track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship agent-track v1: a zero-dependency Cloudflare Worker (D1 + static UI + dual-era MCP endpoint), a SKILL.md, plugin packaging, README, and a live deployment on the CoinStats Main account registered with Claude Code.

**Architecture:** One Worker. `service.ts` owns all rules and is the only thing that touches `db.ts`. `mcp.ts` and `api.ts` are thin adapters over `service.ts`. UI is static files in `public/` talking to `/api/*` and an SSE stream. Spec: `docs/superpowers/specs/2026-09-06-agent-track-design.md`.

**Tech Stack:** TypeScript, Cloudflare Workers, D1, Workers Static Assets, wrangler 4.x, vitest 4.1 + `@cloudflare/vitest-plugin` (tests run inside workerd with a real D1). No runtime npm dependencies.

**Plan conventions:** Interfaces, SQL, schemas and test code are given in full. Straight-line implementation bodies that follow directly from an interface are described rather than duplicated when they exceed ~60 lines (the UI in particular); the executor writes them against the tests. Commit after every task with the attribution trailer.

```ts
export function json(data: unknown, status = 200, headers: Record<string, string> = {}) {

}
const ALPHABET = "0123456789abcdefghjkmnpqrstvwxyz"; // crockford base32, lowercase
export function newId(): string {
  let t = Date.now(); let s = "";
  for (let i = 0; i < 9; i++) { s = ALPHABET[t % 32] + s; t = Math.floor(t / 32); }
  const r = crypto.getRandomValues(new Uint8Array(7));
  for (const b of r) s += ALPHABET[b % 32];
  return s; // 16 chars, time-sortable
}
export function slugify(name: string): string {
  const s = name.toLowerCase().normalize("NFKD").replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "");
  if (!s) throw new HttpError(400, "name must contain letters or digits");
  return s.slice(0, 64);
}
```

```ts
export function timingSafeEqual(a: string, b: string): boolean {
  const enc = new TextEncoder(); const ab = enc.encode(a), bb = enc.encode(b);
  let diff = ab.length ^ bb.length; const n = Math.max(ab.length, bb.length, 1);
  for (let i = 0; i < n; i++) diff |= (ab[i % ab.length] ?? 0) ^ (bb[i % bb.length] ?? 0);
  return diff === 0;
}
export function isAuthorized(request: Request, token: string | undefined): boolean {
  if (!token) return false;
  const h = request.headers.get("authorization") ?? "";
  const m = /^Bearer\s+(.+)$/i.exec(h);
  return !!m && timingSafeEqual(m[1].trim(), token);
}
export function originAllowed(request: Request): boolean {
  const origin = request.headers.get("origin");
  if (!origin) return true;
  return origin === new URL(request.url).origin;
}
```

Exports `handleMcp(request, env): Promise<Response>`.

- Parse body (400 + `-32700` on bad JSON). Batches: if array, process each and return array (legacy allows; modern removed batching → treat array as invalid `-32600` when modern).
- `era = params?._meta?.["io.modelcontextprotocol/protocolVersion"] ? "modern" : "legacy"`.
- Modern: if version ≠ `2026-07-28` → 400 `-32022` `data.supported`; header mismatch → 400 `-32020`. `Mcp-Method`/`Mcp-Name` absent → tolerate (log only). Dispatch `server/discover`, `tools/list`, `tools/call`. Results add `resultType:"complete"`, `_meta.serverInfo`, and for list/discover `ttlMs`, `cacheScope:"public"`. Unknown → 404 `-32601`.
- Legacy: `initialize`, `notifications/initialized` (202), `ping`, `tools/list`, `tools/call`. No id → 202. Unknown → 200 with `-32601` error (legacy) — keep 404 for modern only.
- `tools/call`: validate args → on failure `{content:[{type:"text",text}], isError:true}`. Run via a `callTool(name, args, actor, svc)` switch. Success → `{content:[{type:"text",text:JSON.stringify({data})}], structuredContent:{data}, isError:false}`. `HttpError` from service → `isError:true`; other errors → JSON-RPC `-32603`.
- actor: `args.actor || clientInfo.name || "agent"` where clientInfo comes from `_meta` (modern) or from the `initialize` params on that same request (legacy; stateless so on later calls default is "agent").
- `INSTRUCTIONS` const: 3 lines per spec §4.

index.ts: `POST /mcp` → handleMcp; other methods → 405.
